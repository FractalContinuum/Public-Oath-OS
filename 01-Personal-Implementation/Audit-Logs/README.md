# Audit-Logs README

## 1. 本ディレクトリの目的

本ディレクトリは、Public Oath OS Application Layer における公開監査ログを保存するためのものである。

主な目的は、宣誓供述書に記載した以下の方針について、可能な範囲で継続的に検証可能な状態を維持することである。

* 月16万円程度を目安とする生活費 Assay
* 個人口座および会社口座の公開監査可能性
* 月次残高公開
* 説明責任、公開性、継続性、更新可能性の維持

本公開監査は、全生活情報、全取引明細、全財産情報を無制限に公開することを目的とするものではない。

本ディレクトリにおける公開は、生活費水準および資金状態について、過剰なプライバシー侵害を避けつつ、第三者が時系列上の整合性を確認できる程度の情報を提示することを目的とする。

---

## 2. 公開監査の基本方針

本公開監査では、原則として、銀行口座の月末残高および月次の資金変動を対象とする。

公開対象は、主として以下の情報である。

* 月末時点の銀行口座合計残高
* 当月入金額
* 当月出金額
* 当月差額
* 生活費 Assay に関する判断
* 生活費対象外支出がある場合の補足説明
* 必要に応じた証憑

取引明細そのものについては、取引先、生活行動、決済情報、個人情報、第三者情報等を含むため、原則として全面公開しない。

ただし、公開残高または生活費 Assay について説明が必要となる場合には、必要な範囲で、ネットバンキング画面、領収書、納付書、PDF、スクリーンショットその他の証憑を、必要な墨消しを行った上で `evidence/` フォルダに保存する場合がある。

---

## 3. 生活費 Assay の基準

生活費 Assay の暫定基準は、月16万円程度とする。

ただし、この基準は、単月ごとの絶対上限ではない。

本監査における月16万円基準は、生活水準が過剰化していないかを確認するための暫定基準であり、単月ではなく、年次平均を基準として確認する。

したがって、年次監査においては、以下を一つの目安とする。

* 月16万円 × 12か月 = 年192万円程度

単月で16万円を超える出金があった場合であっても、それが生活費の恒常的増加ではなく、生活費対象外支出、一時支出、資産移動、不測費用等によるものである場合には、その旨を補足説明する。

本監査は、生活費を機械的に毎月16万円以下へ固定するものではなく、年間を通じて生活水準が「足る」の範囲に収まっているかを確認するためのものである。

---

## 4. 生活費対象支出と対象外支出

本公開監査では、口座残高の減少額をそのまま生活費とは扱わない。

口座残高の減少には、生活費以外の支出や資産移動が含まれる場合があるため、必要に応じて以下の区分を行う。

### 4.1 生活費対象支出

生活費 Assay の対象となる主な支出は、以下のとおりである。

* 食費
* 家賃
* 光熱費
* 通信費
* 嗜好品
* 被服費
* 日常生活上の通常支出

現住居はオールインワン型であるため、家賃、光熱費、通信費の一部は一体管理されている。

### 4.2 生活費対象外支出

以下の支出は、原則として生活費 Assay の通常対象から除外し、必要に応じて補足説明の対象とする。

* 公証費用
* 訴訟手数料
* 郵送費
* 裁判関連費用
* 法人関連費用
* サーバー費用
* 税金
* 医療費
* 不測費用
* 設備更新費用
* 事業または研究継続上必要な費用
* その他、生活費とは性質を異にする支出

生活費対象外支出がある場合であっても、すべての証憑を月次で即時公開するとは限らない。

証憑は内部保管を基本とし、必要が生じた場合、または年次監査時に、必要な範囲で公開する。

### 4.3 資産移動

以下は、原則として生活費または消費とは扱わない。

* 自分名義の銀行口座間の資金移動
* 個人口座と会社口座間の資金移動
* 証券口座等を経由した資金移動
* 振込処理中または着金待ちの資金
* 返金、還付、立替精算

資産移動により、月末時点の銀行口座合計残高が一時的に増減する場合がある。

その場合は、必要に応じて補足説明を行う。

---

## 5. 証券口座の取扱い

本公開監査の主対象は、生活費の通常支出経路である銀行口座とする。

証券口座については、現時点において、生活費支出の通常経路として使用していないため、月次公開監査の定期対象には含めない。

また、現時点における証券口座内の残高は少額であり、生活費監査、会社資金監査、および余剰循環判断に実質的影響を与えないものと判断する。

したがって、証券口座は、現時点では本ディレクトリにおける月次公開監査の対象外とする。

ただし、これは財産秘匿を目的として除外するものではない。

今後、証券口座を用いた実質的な資産運用、生活資金管理、または余剰循環判断を行う方針に転換した場合には、必要に応じて宣誓供述書の射程を更新し、再度の宣誓認証および公開を検討する。

---

## 6. 取引明細と内部管理

本公開監査では、原則として残高、入金額、出金額、差額、および必要な補足説明を公開対象とする。

取引明細の全面公開は行わない。

ただし、内部管理上は、資産管理サービス、銀行アプリ、ネットバンキング、通帳、CSV、PDF、スクリーンショットその他の方法により、複数口座の残高および明細を確認可能な状態に保つ。

公開上は最小限としつつ、必要が生じた場合には、内部管理資料、銀行明細、証憑、公開ログを照合できる状態を維持する。

本運用は、自己申告のみで完結させることを目的とするものではなく、必要時に事後照合可能な構造を保持することを目的とする。

---

## 7. 月次公開の時期

月次公開監査ログは、原則として各月末時点の銀行口座合計残高を基準として作成する。

公開時期については、月末日23時59分59秒までの公開を理想とする。

ただし、振込、口座間移動、着金反映、金融機関側の処理時刻、確認作業その他の実務上の事情を考慮し、標準的な公開期限は翌月1日23時59分59秒までとする。

体調、訴訟対応、証憑整理、金融機関側の反映遅延、その他合理的事情により公開が遅れる場合がある。

その場合であっても、可能な限り遅延理由を補足し、遅くとも翌月内には当該月分の公開監査ログを公開する。

なお、月次公開監査ログは、将来月分を前倒しして公開しない。

各月の監査ログは、当該月末時点の残高、当該月の資金移動、および必要な補足事項を確認した上で作成する。

## 8. 2026年6月分の取扱い

2026年6月分は、通常の月次監査ではなく、公開監査開始時点の起点ログとして扱う。

2026年6月19日に、事実実験公正証書および宣誓供述書の作成・認証が完了した。

その後、訴訟関連の検討および記録整理を優先したため、Repositoryへの反映は2026年6月30日以降となった。

したがって、2026年6月分については、通常の月次比較監査ではなく、今後の月次公開監査における基準残高を固定することを主目的とする。

本月については、原則として、2026年6月末時点または公開監査開始時点の銀行口座合計残高を公開する。

通常の月次入金額、出金額、差額、および要件外支出の整理は、2026年7月分以降の月次公開監査から本格運用する。

なお、2026年6月には、公証費用、訴訟手数料、サーバー費用等の生活費対象外支出が発生している。

そのため、仮に当月の出金額または差額が月16万円を超えている場合であっても、それを直ちに生活費 Assay の逸脱とは扱わない。

必要が生じた場合には、当該支出の内訳および証憑を補足説明または年次監査において整理する。

## 9. 年次監査

年次監査では、12か月分の月次公開監査ログを確認し、生活費対象支出が年192万円程度の基準内に収まっているかを確認する。

年次監査では、以下を整理する。

* 各月末銀行口座合計残高
* 各月の入金額
* 各月の出金額
* 各月の差額
* 生活費対象支出の概算
* 生活費対象外支出の内訳
* 資産移動の有無
* 不測費用の有無
* 年192万円基準との整合性

年間の口座残高減少額が192万円を超えた場合であっても、その超過分が生活費対象外支出、資産移動、税金、医療費、公証費用、訴訟費用、法人関連費用、サーバー費用その他の合理的支出である場合には、その内訳を整理する。

必要に応じて、年次監査時に証憑を `evidence/` フォルダへ保存する。

## 10. ディレクトリ構成

本ディレクトリでは、以下の構成を標準とする。

```text
Audit-Logs/
├─ README.md
├─ 2026-06/
│  ├─ README.md
│  └─ evidence/
├─ 2026-07/
│  ├─ README.md
│  ├─ supplemental.md
│  └─ evidence/
└─ Annual-Review/
   └─ 2026.md
```

各月の `README.md` には、月末残高、入金額、出金額、差額、生活費 Assay、要件外支出の有無等を記載する。

要件外支出や資産移動について詳細説明が必要な場合には、同月ディレクトリ内に `supplemental.md` を作成する。

証憑を公開する必要がある場合には、同月ディレクトリ内の `evidence/` フォルダに保存する。

年次監査は `Annual-Review/` に保存する。

## 12. 本公開監査の性質

本公開監査は、法令上の罰則を伴う制度ではなく、自己宣誓に基づく公開監査実装である。

したがって、本ディレクトリにおける運用は、完全性、無謬性、即時性を保証するものではない。

重要なのは、以下の点である。

* 公開可能な範囲を明確にすること
* 公開しない範囲について理由を説明すること
* 誤りや不整合があれば更新すること
* 月次ログと年次監査により時系列上の整合性を確認できること
* 生活費 Assay が過剰な自己演出や財産秘匿ではなく、説明責任に基づく運用であることを示すこと

本公開監査は、絶対的正しさを主張するものではない。

本公開監査は、公開性、継続性、更新可能性、および説明責任を維持するための実装である。
