# 2026年06月 初回公開監査ログ

## 1. 位置づけ

本ログは、2026年06月分の初回公開監査ログである。

2026年06月は、Public Oath OS Application Layer における公開監査の起算開始月である。

そのため、本月は通常の月次入出金監査ではなく、今後の月次公開監査における基準残高を固定することを主目的とする。

## 2. 公開対象

本初回公開監査では、2026年06月末時点の銀行口座合計残高を公開対象とする。

当月の入金額、出金額、差額、生活費対象支出、生活費対象外支出、資産移動、および要件外支出の詳細については、起算開始月につき省略する。

取引明細については、取引先、生活行動、決済情報その他の個人情報を含むため、原則として全面公開しない。

## 3. 起算時点残高

* 基準日：2026年06月30日
* 個人銀行口座合計残高：1,372,715円
* 法人銀行口座合計残高：333円

なお、個人名義内資金移動の反映日の兼ね合いから、上記は6月30日時点での資産合計ではあるが、正確なデータ提示のために7月1日の反映を待って、7月1日のデータを記載している。

## 4. 当月のお金の動き

起算開始月につき、省略する。

本月は、前月末残高との比較、当月入金額、当月出金額、および当月差額を監査対象とせず、2026年06月末時点の銀行口座合計残高を今後の月次公開監査の起点として扱う。

## 5. 生活費 Assay

起算開始月につき、省略する。

通常の生活費 Assay は、2026年07月分以降の月次公開監査ログから本格運用する。
なお、通常の月次入出金監査および生活費 Assay は、2026年07月分以降の月次公開監査ログから本格運用する。

## 6. 要件外支出

起算開始月につき、省略する。

## 7. 証憑

起算開始月につき、省略する。

必要が生じた場合には、内部保管している資料または証憑に基づき、補足説明を行う場合がある。

## 8. 備考

起算開始時点における補助的な参考情報として、以下を記載する。

* 現金：4,069円
* PayPay残高：19円、7pt付与予定59pt

現金およびPayPay残高は、銀行口座合計残高には含めない参考情報である。

本項は、起算開始時点における流動性資産の補助的説明として記載するものであり、2026年07月分以降の月次公開監査において、現金およびPayPay残高を毎月の定期公開対象とすることを意味しない。

ただし、今後、現金またはPayPay残高に監査上重要な変動が生じた場合には、必要に応じて補足説明を行う。
