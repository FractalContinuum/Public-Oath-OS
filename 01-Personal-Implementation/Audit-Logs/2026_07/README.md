# 2026年07月 月次公開監査ログ

## 1. 位置づけ

本ログは、2026年07月分の月次公開監査ログである。

## 2. 公開対象

本月次公開監査では、月末時点の銀行口座合計残高、および当月の入金額、出金額、差額を公開対象とする。

取引明細については、取引先、生活行動、決済情報その他の個人情報を含むため、原則として全面公開しない。

## 3. 月末残高

* 前月末銀行口座合計残高：1,372,715円
* 当月末銀行口座合計残高：1,303,013円
* 2026年07月分家賃控除額：▲65,000円
* 当月末監査上残高：1,238,013円
* 監査上残高差額：▲134,702円

なお、`evidence/個人口座_2026_7月.pdf` 上の合計額は 1,303,013円である。

ただし、住信SBIネット銀行のシステムメンテナンスの関係で、2026年07月分家賃65,000円の振込反映が2026年08月03日となるため、本ログにおける生活費 Assay では、当該家賃分を控除した 1,238,013円 を当月末監査上残高として扱う。
