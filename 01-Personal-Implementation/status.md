# Status

Current status: **Under Notarial Review（公証人確認中）**

## Summary

Public Oath OS の個人実装に関する文書は、現在、公証役場による確認手続中です。

以下の2つの手続について、公証人から受理可能との回答を得ています。

* 宣誓認証（私署証書の認証）
* 事実実験公正証書の作成

関連する草案文書は提出・修正・再提出済みです。
また、公証役場から事実実験公正証書案が提示され、本人確認資料も提出済みです。

ただし、公証手続そのものはまだ実行されていません。

---

## Current Stage

**Under Notarial Review（公証人確認中）**

現在のステータスは、以下の状態を意味します。

* 初回草案を提出済みであること
* 電話およびメールにより目的と構成について確認済みであること
* 宣誓認証および事実実験公正証書の双方について、公証人から受理可能との回答を得ていること
* 修正版の最終草案を提出済みであること
* 公証役場から事実実験公正証書案が提示されていること
* 提示された案について依頼者が確認し了承していること
* 本人確認資料を PDF 形式で提出済みであること
* 現在、公証役場からの次回連絡を待っている状態であること

## Notes

このリポジトリには、現在、公証手続実行前の草案および手続記録が含まれています。

最終的に公証手続が完了した場合、完成版文書は事前草案とは区別して保管する予定です。

公証手続が完了するまでは、特段の記載がない限り、関連資料は草案または実行前資料として扱われます。
