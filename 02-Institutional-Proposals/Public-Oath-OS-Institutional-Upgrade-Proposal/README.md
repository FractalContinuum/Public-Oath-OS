# Public Oath OS Institutional Upgrade Proposal

## 公証宣誓OSによる国家制度アップデート構想

このディレクトリには、**Public Oath OS の制度提案における本編**を格納しています。

本提案は、日本に既に存在する公証制度、行政制度、司法制度、国籍制度、選挙制度、政治資金制度、公務員制度その他の制度資源を再発見・再配置し、宣誓（Oath）を国家制度レベルの共通プロトコルとして利用する可能性を検討するものです。

新たな監視権力を無条件に追加するのではなく、既存の公証、宣誓、本人確認、署名認証、記録、説明、反証および違反認定手続を接続することで、透明性、説明責任および検証可能性を高めることを目的とします。

## 基本構造

本提案は、以下の構造から成ります。

### Core Principles

* 透明性核
* 宣誓プロトコル
* 説明義務結合
* 非強制アップデート
* 強推定ファクトの取扱原理

### Oath Protocol Types

* `OP-L1`：すべての宣誓に共通する基底プロトコル
* `OP-L2`：公的地位・権限等に応じた職位別プロトコル
* `OP-L3`：帰化、特別任務、高リスクデータ取扱い等に応じた状況依存プロトコル

### Architecture

* 物理宣誓層
* Digital Twin / ハッシュ台帳層
* Trust Badge / Verifiable Credential 層
* 制度モジュール層

### Triggers and Synchronization

* 権限取得
* 高リスク情報へのアクセス
* 帰化その他の法定手続
* 任意宣誓
* 個人・行政司法・社会との三方向同期

### Oath-Breach State Machine

```text
S0：通常状態
↓
S1：合理的疑義の発火
↓
S2：説明・反証フェーズ
↓
S3：正式な違反認定手続への移行
```

疑義が生じたことのみをもって、直ちに宣誓違反または法的責任を確定するものではありません。

説明および反証の機会を保障し、個別法上の要件と適正な手続に基づいて、正式な責任判断へ接続する構造を採ります。

### Strong-Presumption Fact Responsibility

本人による明示的な宣誓、本人確認、署名の真正担保、説明・反証手続等によって形成される強推定ファクトは、強い社会的・制度的影響を持ち得ます。

そのため、本提案は、強推定ファクトを生成する仕組みだけでなく、その不正確な引用、文脈切断、手続段階を無視した断定および政治的濫用を防ぐための説明責任原則を併設します。

## 安全弁

本提案は、宣誓を次のような目的に利用することを否定します。

* 思想・信条への包括的同調強制
* 一般国民に対する恒常的監視
* 未宣誓者への自動的な不利益評価
* 手続を経ない宣誓違反認定
* 政敵・報道機関・特定集団への攻撃
* 公益通報または正当な情報提供の封鎖
* 宣誓文の無制限な拡張解釈
* 強推定ファクトを用いた恣意的なラベリング

宣誓内容は、付与される公的権限、情報アクセス、資格または法定手続の目的と合理的に関連する、限定的かつ明確な内容でなければなりません。

## NO-Capture / NO-Animus

本提案は、特定の国家、政党、思想、組織、企業または権威による独占的Captureを目的としません。

また、特定の国家、国民、文化、組織または個人に対する敵意を目的とするものではありません。

制度批評は、人格的または国家的敵対ではなく、制度上の問題、運用上の矛盾、濫用可能性および改善可能性を対象とします。

本提案は、参照、批評、改変、派生実装および再構成が可能な制度設計素材として公開されます。
