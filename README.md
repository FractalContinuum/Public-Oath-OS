# Public-Oath-OS
Public Oath OS: open implementation of personal governance through notarial execution, auditability, and institutional extensions.

## 概要

本Repositoryは、

・公正証書

・宣誓認証

・GitHub

・README

・公開ログ

・更新履歴

・制度提言

等を組み合わせ、個人が公開自己統治・説明責任・公開監査を実装するための「Public Oath OS（公証宣誓OS）」と

その過程で得られた制度的知見の提言・公開を行うための、実験的公開Repositoryです。

本Repositoryは、政治活動・宗教活動・国家転覆・特定勢力への忠誠を目的とするものではありません。

本Repositoryは、既存制度を活用し、個人が自己行動原理を公開し、継続的に説明責任を負う構造を実装可能か検証する「事実実験」を目的としています。

## Core Concepts
### NO-Capture

特定勢力・特定権威・特定解釈による意味固定化（Capture）を拒否する。

### 資国不害

Absence of Animus, Allocation to the Collective.

共同体・公共循環に対し、害意無く、資源・行動・能力を配置する。

ここでいう「不害」は、一切の批判や是正を否定する意味ではない。

本OSは、説明責任を重視する。

### 知恥識足

Awareness of Shame, Assay of Sufficiency.

「恥」を自己監査機構として扱い、「足る」を固定値ではなく動的Assay対象として扱う。

## Explanation Responsibility

本Repositoryは、「絶対的正しさ」ではなく、「説明責任」を重視します。

そのため、

・README

・補足文書

・更新履歴

・GitHub Issue

・公開ログ

等を用いて、継続的説明責任を行います。

また、本Repositoryについて批判・疑義・反論を行う場合、公開済み資料へのアクセスおよび読解を前提条件とします。

未読状態・切り抜き状態・意味固定状態による断定的反応については、原則として応答対象外とします。
